## **1. 📱 Стилистика проекта (SCSS + Naive UI)**

Стек: **Vue 3**, **SCSS** (без Tailwind), **Naive UI**. Стили — в `resources/scss/` и scoped-блоках компонентов.

### **1.1 variables.scss**

Цвета, типографика, отступы, брейкпоинты, радиусы, тени, миксины:

- **Акценты:** `$primary-color: #1062b9`, `$success-color: #22c55e`, `$text-logo: #249969`
- **Текст:** `$text-color: #273a55`, `$text-light-grey`, `$text-dark-grey`
- **Фон:** `$bg-gray: #fbfbfb`, `$bg-light-primary`, `$white-color`
- **HACCP-статусы:** `$task-incomplete-*` (красный оттенок), `$task-completed-*` (зелёный)
- **Типографика:** `$font-family-rubik`, размеры от `$font-size-xs` до `$font-size-4xl`
- **Spacing:** `$spacing-xs` … `$spacing-2xl`
- **Breakpoints:** `$breakpoint-sm: 640px`, `md: 768`, `lg: 1024`, `xl: 1280`
- **Radius:** `$radius-sm` … `$radius-xxxl`, `$radius-full`
- **Тени/переходы:** `$shadow-sm` … `$shadow-2xl`, `$transition-fast/base/slow`
- **Миксин:** `@include respond-to(sm|md|lg|xl|max-lg) { ... }`

### **1.2 app.scss (глобальные стили)**

- `body`: `$font-size-base`, `$text-color`, `$bg-gray`, Rubik
- `.container`: max-width 1440px, padding по `$spacing-md`
- `#app`, `.app-wrapper`, `.main-content`: flex-верстка, min-height 100vh
- `.logo-link`: цвет `$text-logo`, hover opacity
- `h1`: адаптивный размер (48px → 60px по брейкпоинтам)
- `a`, `p`: ссылки и параграфы по дизайн-системе
- **Кнопки:** `.btn-client` (база) + модификаторы:
    - `.btn-primary` — синий фон
    - `.btn-success` — зелёный
    - `.btn-outline-primary` — обводка
    - `.btn-text` — без фона
- Формы: `.label-svg`, `.box-search-select`, `.box-radio`

### **1.3 Компоненты (scoped SCSS)**

- В каждом компоненте: `@use "../../../scss/variables" as *;` (путь относительно файла)
- Карточки задач: `.task-card`, `.task-card--completed` (фон/бордер из `$task-incomplete-*` / `$task-completed-*`)
- Адаптив через `@include respond-to(sm)` и т.д.
- UI-компоненты: **Naive UI** (NCard, NTag, NAlert, NProgress, NForm и т.д.) — темы и отступы через пропсы/тему Naive

**Использовать эту стилистику для всех новых страниц и компонентов (Landing, Demo, опросник).**
