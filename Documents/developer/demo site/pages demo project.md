## Публичные страницы по QR-ссылке

`{batchId}` и `{YYYY-MM-DD}` — заменить на реальные значения. Опционально `?print=1` для версии под печать.

- Карточка партии EUDR — https://demo.haccpilot.eu/en/batch/{batchId}
- Дневной отчёт HACCPilot — https://demo.haccpilot.eu/en/report/{YYYY-MM-DD}
